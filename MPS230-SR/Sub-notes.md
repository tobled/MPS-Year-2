## 1.2 Terminology

Nucleon - A proton or a Neutron

Atomic Number ($Z$) - The proton number which determines charge in a nucleus

Atomic Mass Number ($A$) - Total number of nucleons in a nucleus, $N = A - Z$ where N is the number of neutrons

Nuclide - A nucleus with specific $Z$ and $A$ values, e.g., ${}^{14}_{7}\text{C}$

Isotope - A nucleus with a given atomic number $Z$, but different atomic mass numbers $A$

Isobar - nuclei with the same atomic mass number $A$, but different atomic numbers $Z$

Isotone - A nucleus witha a given number of neutrons N, but a different number of protons
